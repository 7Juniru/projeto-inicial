2. Os Pilares da Programação Orientada a Objetos (POO)

Java é uma linguagem Orientada a Objetos. Em POO, tentamos representar coisas do mundo real dentro do código usando Classes e Objetos.

💡 Conceitos-Chave da POO:

  • Classe: É o "molde" ou a "planta baixa". Define o formato e o comportamento. Exemplo: A classe Product define o que todo produto tem (nome, validade, quantidade).
  • Objeto (Instância): É o item real criado a partir da classe. Exemplo: Um objeto específico "Leite Integral, vence em 10/08/2026".
  • Atributos (Campos): São as características/variáveis de um objeto (ex: nome, quantidade).
  • Métodos: São as ações ou funções que um objeto pode executar (ex: saveProduct(), getId()).
  • Encapsulamento: Proteção dos dados da classe usando o modificador private para evitar alterações indevidas diretamente de fora.
